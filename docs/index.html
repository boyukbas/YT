Lines

Tap a line to fix the text. The tag switches language and color. Start/End move a line earlier or later by 0.1 s. Changing words per line rebuilds the lines and drops text fixes.

Speech recognition

The video's sound is sent to OpenAI and comes back as text in seconds, however slow this device is. About $0.006 per minute of video. Needs your own OpenAI API key (sk-proj-…), stored only on this device. OpenAI doesn't mark languages — with a Claude key added below, Claude does that automatically.

Accuracy

Claude not set up

Optional: with your own Claude API key, Claude fixes the transcript using the context and marks each line's language. Claude can't hear audio, so the speech recognition still runs on this device. The key is stored only on this device and is never logged — set a spending limit in the Claude Console.

Combine videos

Help & diagnostics

The app keeps a small log of what happened (no video, no subtitle text) on this device only. If something goes wrong, copy it and paste it to Claude, or report it on GitHub.
