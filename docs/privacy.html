Privacy policy

Shorts Editor · last updated 1 November 2026

Shorts Editor is a personal video tool made for one YouTube channel, Almanca Dil Atölyesi. It is not offered to the public as a service. It has two parts: this web app, which runs entirely in your browser, and a helper program on the channel owner's own computer.

What the YouTube permission is used for

When the channel owner signs in with Google, the helper program asks for access to the channel's YouTube account (youtube.force-ssl). It uses it only to manage that channel's own videos:

  • find the video the owner just uploaded;
  • set its title, description, tags, category, language, audience and publish time;
  • upload its thumbnail and caption tracks, add it to a playlist and post a comment from the channel.

It does not read, collect or change anything else, and it never acts on other people's channels.

Where data is kept

  • The sign-in token is stored only on the channel owner's computer. It is never sent anywhere except to Google.
  • Videos, captions and texts stay on the owner's devices and in the owner's own Google Drive.
  • The web app keeps projects and settings in the browser on your device. Optional API keys you enter are stored only in that browser.

Sharing

No data is sold, shared with third parties, used for advertising or used to train AI models. There are no analytics or tracking cookies. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the helper program's token file on the computer removes the stored sign-in as well.
